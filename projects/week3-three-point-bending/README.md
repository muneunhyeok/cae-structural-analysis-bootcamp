# 3주차 — 3점 굽힘: 이론해와 해석 결과 비교

> **과제**
> ① 3점 밴딩 모델에 대한 해석을 진행하고 **해석 결과와 이론 결과를 비교**할 것
> ② **오차 발생 원인**에 대해 기술할 것

> ⚠️ **이 문서는 과제 조건과 이론 프레임 정리다.**
> 해석 수행 결과 보고서는 본 저장소에 포함하지 않았다.
> 아래 비교표의 수치 칸은 의도적으로 비워 두었다.

## 1. 과제 조건

### 모델 구성

```
        FORCE JIG  ↓ Z방향 강제변위 3 mm
             ▼
    ═════════════════════   ← PLATE (t = 0.2 mm)
      ▲               ▲
   FIX JIG         FIX JIG
```

| 구분 | 값 |
|---|---|
| **하중 조건** | Z방향 **3 mm** 강제변위 (FORCE JIG) |
| PLATE 두께 | 0.2 mm |
| 지그 반경 / 간격 | 2.5 mm, 3.5 mm, 3.5 mm, 10 mm (과제 도면 기준) |

### 재료 물성

| 구분 | Value |
|---|---|
| 인장탄성계수 $E$ | **193,000 MPa** |
| 포아송비 $\nu$ | **0.29** |

| Stress (MPa) | Strain |

| 206 | 0 |

## 2. 이론해 프레임

### 단순지지 보의 3점 굽힘

스팬 $L$, 폭 $b$, 두께 $h$ 인 직사각 단면의 단순지지 보 중앙에 하중 $P$ 가 작용할 때:

| 항목 | 식 |
|---|---|
| 단면 2차 모멘트 | $I = \dfrac{bh^3}{12}$ |
| 단면계수 | $Z = \dfrac{bh^2}{6}$ |
| 최대 굽힘 모멘트 (중앙) | $M_{max} = \dfrac{PL}{4}$ |
| 최대 굽힘 응력 | $\sigma_{max} = \dfrac{M_{max}}{Z} = \dfrac{3PL}{2bh^2}$ |
| 중앙 처짐 | $\delta = \dfrac{PL^3}{48EI}$ |

### 본 과제는 변위 제어이므로 역순으로 푼다

하중이 아니라 **강제변위 $\delta$ = 3 mm** 가 주어졌으므로:

$$P = \frac{48EI\delta}{L^3} \qquad\Rightarrow\qquad \sigma_{max} = \frac{3L}{2bh^2}\cdot\frac{48EI\delta}{L^3} = \frac{6Eh\delta}{L^2}$$

여기서 $\sigma_{max} = \dfrac{6Eh\delta}{L^{2}}$ 는 **폭 $b$ 와 무관**하다는 점이 눈에 띈다.
변위 제어에서는 폭을 늘려도 반력만 비례해 커질 뿐 굽힘 응력은 그대로다.
(2주차에서 폭 확대가 응력을 줄인 것은 **하중을 고정한 조건**이었기 때문이다 → [2주차](../week2-contact-stress/))

## 3. 오차가 발생할 수밖에 없는 이유

과제가 요구한 핵심은 "오차 발생 원인"이다. 이 모델은 **초기 조건 자체가 보 이론의 가정을 벗어난다.**

### ① 재료비선형 — 항복을 한참 넘긴다

이론식은 후크의 법칙(선형 탄성)을 전제한다.
그런데 $t$ = 0.2 mm 판에 3 mm 처짐이면 **처짐이 두께의 15배**다.
탄성 이론으로 계산한 응력은 항복응력 206 MPa를 **수십 배 초과**하는 값이 나온다.

실제로는 소성이 발생해 응력이 재분배되므로, **해석 결과가 이론값보다 훨씬 낮게** 나온다.
→ 이론식이 과대평가하는 방향.

### ② 기하비선형 — 대변형·막응력(membrane) 지배

처짐이 두께보다 훨씬 크면 굽힘만으로 하중을 지지하지 않는다.
판이 늘어나며 **인장 막응력(membrane stress)** 이 하중의 상당 부분을 받는다.

- 보 이론: 처짐 ∝ 하중 (선형)
- 실제: 처짐이 커질수록 강성이 증가 (**stiffening**)

→ 반력이 이론 예측과 다른 방향으로 벗어난다.
→ `Nlgeom: On` 필수. 끄고 돌리면 결과 자체가 무의미하다.

### ③ 경계비선형 — 지그는 핀 지지가 아니다

이론식의 "단순지지"는 회전이 자유롭고 위치가 고정된 이상적 핀이다.
실제 모델은 **곡률을 가진 JIG와의 접촉**이다.

| 이론 | 실제 |
|---|---|
| 지지점 위치 고정 | 판이 지그 위에서 **미끄러지며 접촉점이 이동** → 유효 스팬 $L$ 이 변한다 |
| 마찰 없음 | 마찰이 막응력 전달에 관여 |
| 점 지지 | 유한한 접촉 면적에 하중 분산 |

$\sigma_{max} \propto 1/L^2$ 이므로 **유효 스팬의 변화가 응력에 제곱으로 증폭**되어 들어온다.
이것이 이 모델에서 가장 크게 작용하는 오차 요인이라고 본다.

### ④ 응력집중 — 이론식에 없는 항

FORCE JIG가 판을 누르는 접촉부에는 국부 접촉 응력이 발생한다.
보 이론의 $\sigma = M/Z$ 에는 이 항이 아예 없다.
해석에서 잡히는 최대응력 위치가 **중앙 단면이 아니라 접촉부**로 나올 수 있다.

### ⑤ 얇은 판 = 쉘 요소의 전제

두께 0.2 mm는 길이 대비 1/10보다 훨씬 얇으므로 쉘 요소 영역이다.
쉘 요소는 절점당 **회전 자유도 3개**를 추가로 가지며, 두께 방향 응력 분포를 적분점으로 표현한다.
컨투어를 읽을 때 **SNEG / SPOS(상·하면)** 중 어느 면인지 확인하지 않으면 값이 달라진다.

## 4. 정리 — 이론값은 무엇에 쓰는가

| | 이론해 | 유한요소해석 |
|---|---|---|
| 재료 | 선형 탄성만 | 소성 반영 |
| 변형 | 미소변형 | 대변형·막응력 |
| 경계 | 이상적 핀 지지 | 접촉·마찰·스팬 변화 |
| 응력집중 | 표현 못 함 | 표현됨 |

**이 조건에서 이론값과 해석값이 일치할 것을 기대하는 것 자체가 잘못된 기대다.**
이론해의 역할은 정답을 주는 것이 아니라 **자릿수 검산(sanity check)** 이다.

> 해석 결과가 이론값과 **자릿수 단위로** 벗어나면 모델링 실수(단위계, 물성, BC)를 의심하고,
> **몇 배 수준**의 차이라면 위 ①~④ 중 어느 비선형이 지배하는지 설명할 수 있어야 한다.
>
> 4주차에서 에너지 수지로 반력을 교차검증한 것도 같은 발상이다.
