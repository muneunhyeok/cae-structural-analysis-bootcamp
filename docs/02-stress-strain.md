# 02. 재료 물성과 응력-변형률 선도

> 해석 정확도의 출발점은 솔버가 아니라 **입력 물성**이다.

---

## 1. 공칭 응력-변형률 선도 (Nominal / Engineering)

### 공칭 응력 (nominal stress, engineering stress)

$$\sigma_{nom} = \frac{P}{A_0}$$

하중 $P$ 를 시험편의 **원래 단면적** $A_0$ 로 나눈 것.
→ 단면적 전체와 표점거리 전체에 걸쳐 **응력이 일정하다고 가정**한 값이다.

### 공칭 변형률 (nominal strain, engineering strain)

$$\varepsilon_{nom} = \frac{\Delta L}{L_0}$$

표점거리의 변화량을 **원래의 표점거리** $L_0$ 로 나눈 것.
또는 **스트레인 게이지(Strain gage)** 로 변형률을 바로 읽는다.
→ 표점 사이의 영역 전체에 걸쳐 **변형률이 일정하다고 가정**한 값이다.

---

## 2. 진 응력-변형률 선도 (True)

### 진응력 (True stress)

$$\sigma_{true} = \frac{P}{A_{inst}}$$

하중이 측정되는 **순간에 측정한 시편의 실제 단면적**으로 나눈 것.

### 진변형률 (True strain)

$$\varepsilon_{true} = \ln\!\left(\frac{L_{inst}}{L_0}\right)$$

하중이 측정되는 **순간에 측정한 시편의 실제 길이**를 기준으로 한 것.

---

## 3. 왜 구분해야 하는가

| | 공칭 | 진 |
|---|---|---|
| 기준 단면적 | 원래 단면적 $A_0$ (고정) | 순간 단면적 $A_{inst}$ (감소) |
| 소성 구간에서 | 실제보다 **낮게** 나온다 | 실제 응력 |
| 네킹 이후 | 곡선이 **하강**(가짜 연화) | 계속 상승 |

시편은 늘어나면서 단면이 줄어든다. 그런데 공칭 응력은 줄어들지 않은 $A_0$ 로 나누므로,
**소성이 진행될수록 실제보다 작은 값**을 준다.

### 해석 입력으로 무엇을 넣어야 하는가

> **Abaqus의 소성(Plastic) 물성 입력은 진응력–진소성변형률을 요구한다.**
> 인장시험에서 얻은 공칭 데이터를 그대로 넣으면 소성 구간이 실제보다 무르게 계산된다.

변환식 (네킹 발생 전 균일변형 구간에서만 유효):

$$\sigma_{true} = \sigma_{nom}(1 + \varepsilon_{nom}) \qquad \varepsilon_{true} = \ln(1 + \varepsilon_{nom})$$

$$\varepsilon_{pl} = \varepsilon_{true} - \frac{\sigma_{true}}{E}$$

1주차 업무 절차서의 Property 설정 단계에 **"소성 거동이 예상될 경우 진응력-진변형률 곡선을 추가로 정의한다"**
라고 적은 근거가 이것이다.

## 4. 과제에서 사용한 재료 물성

### 2주차 — Contact 부품

| 항목 | 값 |
|---|---|
| 탄성계수 $E$ | 200 GPa |
| 포아송비 $\nu$ | 0.29 |
| 소성 데이터 | 250 MPa @ strain 0 → 850 MPa @ strain 0.06 |
| 요소 / 두께 | Shell / 0.6 mm |

→ strain 0에서의 250 MPa가 **항복응력**이고, 850 MPa는 소성이 진행된 지점의 값이다.
따라서 판정 기준은 **250 MPa(항복)** 로 잡는 것이 타당하다고 보았다.

> 최대응력 393.5 MPa를 850 MPa와 비교하면 안전율 2.16으로 여유가 있어 보이지만,
> **실무 설계 검토에서는 항복 발생 여부를 먼저 본다.**
> 250 MPa 기준 안전율은 0.64로 불만족이다.
> → [2주차 보고서](../projects/week2-contact-stress/)

### 3주차 — PLATE

| 항목 | 값 |
|---|---|
| 인장탄성계수 $E$ | 193,000 MPa |
| 포아송비 $\nu$ | 0.29 |
| 소성 데이터 | 206 MPa @ strain 0 → 848 MPa @ strain 0.47 |

$E$ = 193 GPa, $\nu$ = 0.29 → **스테인리스강(STS 304 계열)** 의 전형적인 물성이다.
strain 0.47까지의 큰 연신은 오스테나이트계 스테인리스의 특징과 일치한다.

### 4주차 — 전 부품 강체(Rigid)

물성 입력 없음. 대신 **참조점에 미소 점질량**을 부여했다.

| 대상 | 점질량 |
|---|---|
| 부품 참조점 | 1×10⁻⁴ tonne |
| 지면 참조점 | 1×10⁻⁶ tonne |

강체에는 탄성계수가 의미 없지만, 질량이 0이면 접촉 분리 시 **zero pivot / 수치 특이점**이 발생한다.
→ [03. 트러블슈팅 로그](03-troubleshooting-log.md)

## 5. 단위계

Abaqus는 단위를 강제하지 않으므로 **입력자가 일관성을 책임진다.**
본 과제 전체에서 사용한 단위계:

| 물리량 | 단위 |
|---|---|
| 길이 | mm |
| 힘 | N |
| 응력 | MPa (= N/mm²) |
| 질량 | **tonne** (= 10³ kg) |
| 시간 | s |
| 밀도 | tonne/mm³ |

> 질량 단위가 kg이 아니라 **tonne**이라는 점이 이 단위계의 함정이다.
> mm–N–s 계에서 $F = ma$ 가 성립하려면 질량이 tonne이어야 한다.
> 강재 밀도를 7.85e-9 tonne/mm³로 넣는 이유이고,
> 4주차 점질량을 1e-4 tonne(= 0.1 g)로 지정한 이유다.
