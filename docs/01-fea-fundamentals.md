# 01. 유한요소해석 기초

> 강의 교안 정리 + 과제에서 실제로 적용된 지점 표시

---

## 1. 유한요소법의 기본 개념

정확한 이론해를 구하기 어려운 문제에 대한 **수치적 근사해법(approximation method)** 이다.

```
복잡한 모델
   ↓ 분할
유한개의 요소(Element)
   ↓ 개별 요소의 특성 계산
   ↓ 전체 요소 특성 조합
전체 모델의 특성을 근사적으로 계산
```

| 용어 | 정의 |
|---|---|
| **절점(node)** | 결과(미지수)가 계산되는 위치. 일반적으로 요소의 꼭지점. 요소의 모양과 위치를 정의한다 |
| **자유도(DOF)** | 절점이 갖는 미지수. 예) 온도해석의 온도, 응력해석의 변위 |

> **핵심**: 해석 결과는 절점에서 계산된다. 요소 중앙의 값은 절점값으로부터 보간된 것이다.

## 2. 강성(Stiffness)

**단위변형을 발생시키는 데 필요한 힘의 크기.**

| 강성이 크다 | 강성이 작다 |
|---|---|
| 단위변형에 더 큰 힘이 필요 | 작은 힘으로도 쉽게 변형 |
| 구조물이 강하다 / 뻣뻣하다 | 구조물이 약하다 / 유연하다 |

유한요소법의 행렬 방정식:

$$[K]\{u\} = \{F\}$$

- $[K]$ : 강성행렬
- $\{u\}$ : 자유도 (구하고자 하는 미지수)
- $\{F\}$ : 하중벡터

### 과제 적용 — 강제변위 해석에서 이 식을 읽는 법

2주차·4주차 과제는 모두 **$\{u\}$ 를 지정하고 $\{F\}$ 를 구하는** 변위 제어 해석이었다.
일반적인 하중 제어와 방향이 반대다.

| | 하중 제어 | 변위 제어 (과제 조건) |
|---|---|---|
| 입력 | $\{F\}$ | $\{u\}$ (예: U2 = −3 mm, U3 = −5 mm) |
| 출력 | 변위 | **반력 RF** |
| 형상을 강화하면 | 변위 ↓ | **반력 ↑** (변위가 고정이므로) |

이 차이 때문에 2주차 개선안에서 **"형상을 바꾼 뒤 같은 −3 mm를 그대로 유지하면 반력이 달라지므로,
RF ≈ 205.8 N이 되도록 맞춘 조건에서 응력을 비교해야 한다"** 는 조건을 붙였다.
→ [2주차 보고서](../projects/week2-contact-stress/)

## 3. 자유도와 해석 비용

- 행렬방정식에서 구하는 미지수는 **자유도**이며,
  해석 종류·요소 종류에 따라 **자유도의 물리적 의미, 절점당 자유도의 종류와 개수**가 달라진다
- $[K]$ 의 크기는 자유도 개수 $N$ 에 비례한다
- 따라서 **메모리 사용량과 해석 시간에 가장 큰 영향을 미치는 인자 = 모델 전체 자유도 개수**

```
전체 자유도 개수 ≈ 총 절점 개수 × 절점당 자유도 개수
```

### 과제 적용 — 1,000 노드 제한을 요소 배분 문제로 바꾸기

Abaqus Learning Edition은 **1,000 노드 제한**이 있다.
이 식이 곧 "절점 예산"이므로, 4주차에서는 전체를 균등하게 나누는 대신
**접촉이 지배적인 JIG 곡면에 절점을 몰아주고** 나머지를 성글게 처리해 총 700개 내외로 맞췄다.
(원주당 요소 20개 이상 확보 → 접촉 채터링 해소)

## 4. 요소(Element) 종류

| 요소 | 절점당 자유도 | 사용처 |
|---|---|---|
| **솔리드 요소** | 병진 3개 (U1, U2, U3) | **실무에서 가장 많이 사용** |
| **쉘 요소** | 병진 3개 + 회전 3개 (U1~UR3) | 두께가 얇은 박판 구조물 (두께 < 길이의 1/10) |

> 쉘 요소가 회전 자유도를 갖는다는 점이 중요하다.
> 2주차 Contact 부품(두께 0.6 mm)에 Shell을 적용한 이유이자,
> 경계조건에서 UR1~UR3까지 구속 지정이 필요했던 이유다.

## 5. 요소망(Mesh) 작성 지침

### 요소 형상 선택

| 구분 | 권장 | 자제 |
|---|---|---|
| **솔리드** | 저차 육면체 요소 **또는** 고차 사면체 요소 | 저차 사면체 요소 |
| **쉘** | 저차 사각형 요소 | 저차 삼각형 요소 |

**저차 사면체/삼각형 요소는 상대적으로 강하게(Stiff) 거동**하여 변위·응력이 작게 계산되므로 가급적 자제한다.

> ⚠️ 단, **모양이 나쁜 육면체/사각형 요소보다는 모양이 좋은 사면체/삼각형 요소가 더 낫다.**
> 요소 종류보다 요소 품질이 우선이다.

### 요소 품질

- 요소는 **크기가 작고, 정다면체/정다각형에 가까운 형상**일수록 결과가 좋다
- **모달 / 좌굴 / 비선형 해석은 요소 모양에 더 민감**하게 반응하므로 좋은 모양의 요소가 필요하다

### 요소망 조밀도 — 정확도 vs 경제성

| 요소망을 조밀하게 하면 | |
|---|---|
| ✅ | 해석 결과의 정확도 향상 |
| ❌ | 절점·요소 증가 → 해석 시간·메모리 증가 |

**조밀한 요소망이 필요한 부위**
- 기하형상의 변화가 심한 부분
- 응력집중이 예상되는 부분
- 재질 및 하중이 변하는 부분

### 과제 적용 — 메시 독립성 검토를 개선안에 포함시킨 이유

2주차에서 최대 응력 393.5 MPa가 **수치적 피크인지 실제 응력집중인지** 구분되지 않았다.
그래서 개선안 우선순위 4번에 **"고응력부 mesh 세분화 후 재해석 → 메시 독립성 검토 후 최종값 채택"** 을 넣었다.
숫자 하나를 그대로 설계 판정에 쓰기 전에 거쳐야 하는 단계다.

## 6. 유한요소해석의 종류

### 선형정적해석

아래 **3가지 전제가 모두 성립**해야 선형정적해석이 유효하다.

| 전제 | 깨지면 |
|---|---|
| 재료가 탄성영역 내에서 후크의 법칙을 따름 (하중-변위, 응력-변형률이 선형) | **재료비선형** — 소성영역 고려 필요, 고무처럼 미소변형률에서도 비선형인 경우 |
| 발생 변형이 구조물의 강성변화를 무시할 수 있을 만큼 작음 | **기하비선형** — 대변형(대변위, 대회전) |
| 하중 작용 중 경계조건이 변하지 않음 | **경계비선형** — 대표적으로 **접촉해석(contact analysis)** |

> 2주차·4주차 과제 모두 **접촉해석**이므로 경계비선형에 해당한다.
> 4주차는 여기에 대회전(BUTTON UR1 ≈ −16°)까지 있어 **Nlgeom: On**으로 기하비선형을 함께 켰다.

### 모달 해석
- 외력과 감쇠(damping)가 없는 조건에서 **고유진동수**와 진동수별 **모드형상**을 계산
- 활용: 부품이 공진을 피하도록 설계, 시스템 운영 진동수에서의 변형형상 파악/유도

### 열전달해석
- 물체의 온도분포 계산 → 열이 흐르는 방향과 크기 파악

| 구분 기준 | 종류 |
|---|---|
| 조건이 시간에 따라 변하는가 | 비정상(transient) / 정상상태(steady-state) |
| 조건이 온도에 따라 변하는가 | 비선형 / 선형 |

- 온도와 **온도구배(temperature gradient)** 는 열변형·열응력의 주요 발생 요인
- 실무에서는 열전달해석으로 온도분포를 구한 뒤 **열변형/열응력을 추가 계산**하는 경우가 많다

### 비선형 해석 3종

| 종류 | 내용 |
|---|---|
| **재료비선형** | 소성영역 고려, 고무처럼 응력-변형률이 선형이 아닌 재료. 적절한 재료모델 선택 후 응력-변형률 관계 지정 |
| **기하비선형** | 변위-변형률 관계가 비선형. 변형이 커지면 **재료 물성과 무관하게 구조물 강성이 변한다**. 작용 하중의 크기·방향도 변할 수 있어 변형된 형상 기준으로 재계산 필요 |
| **접촉비선형** | 하중에 의해 모델이 움직이거나 변형되며 **경계조건이 변한다**. 두 영역이 만나거나 미끄러지거나(sliding) 붙었다 떨어지는 상대거동을 분석 |
