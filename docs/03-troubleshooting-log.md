## 1. SEGMENTATION FAULT — 가장 오래 붙잡은 실패

### 증상
```
Increment 57 → SEGMENTATION FAULT
```
수렴이 안 되는 것이 아니라 **솔버가 비정상 종료**했다.

### 진단 과정
메시지 파일을 보니 수렴 실패 이전에 다음이 선행되어 있었다.
- 72개 접촉요소가 **강제로 Lagrange multiplier로 전환**됨
- 이후 발산과 라인서치 축소를 반복

Step 설정을 확인하니 **Solution technique이 Quasi-Newton**이었다.

### 원인
> **Quasi-Newton 방식은 Penalty 접촉과 병용할 수 없다.**

Quasi-Newton은 강성행렬을 매 반복마다 새로 만들지 않고 근사 갱신으로 재사용해 비용을 아끼는 방식이다.
그런데 Penalty 접촉은 접촉 상태가 바뀔 때마다 강성이 불연속적으로 변한다.
Abaqus는 이 조합을 처리하지 못하고 접촉 구속을 Lagrange multiplier로 바꿔버리는데,
이 과정에서 시스템이 깨지며 세그폴트로 이어졌다.

### 조치
**Solution technique → Full Newton**

동일한 모델이 **126 증분 만에 완주**했다.

### 배운 것
접촉이 지배적인 해석에서 솔버 옵션은 "결과의 정확도"가 아니라 **"결과의 존재 여부"** 를 결정한다.
그리고 이런 실패는 모델을 아무리 들여다봐도 안 보인다 — **메시지 파일을 읽어야 보인다.**

## 2. 수렴 실패 — 접촉 채터링

### 증상
```
Too many attempts needed
```

### 원인
반경 **1 mm** JIG 반원통의 원주 분할이 **8개**에 불과했다.
곡면이 8각형으로 근사되면 접촉점이 요소 경계를 넘을 때마다 접촉 판정이 반복 반전(채터링)한다.
솔버 입장에서는 매 시도마다 접촉 상태가 바뀌므로 수렴할 수가 없다.

### 조치
Seed의 **deviation factor를 낮춰 원주당 요소 수를 20개 이상** 확보.

### 남은 한계 (정직하게)
Learning Edition의 1,000 노드 제한 때문에 이 이상 세분화하지 못했고,
해석 종료까지 `20 elements are curved/warped` 경고가 남아 있었다.

곡면을 다각형으로 근사하면 접촉점이 계단식으로 이동하므로 **하중 곡선에 작은 굴곡이 생긴다.**
노드 제한이 없는 환경에서 더 세분화하면 곡선이 매끄러워지고,
[하중 이력의 t ≈ 0.58 불연속](../projects/week4-pushbutton-mechanism/)이
**접촉 전이인지 수치적 요인인지 명확히 구분**할 수 있을 것이다.

## 3. 반력이 0으로 나온 것 — 오류가 아니었다

### 증상
JIG를 5 mm 눌렀는데 **RF3 = 2.77×10⁻¹⁸ N**. 사실상 0.

### 먼저 확인한 것
같은 시점의 **U3가 정확히 −5 mm** 였다.
→ 강제변위는 정상 적용되었다. 즉 BC 설정 실수가 아니다.

### 원인 — 물리적으로 옳은 결과
```
BUTTON  : Hinge 커넥터로 자유롭게 회전
PIECE   : Translator 커넥터로 자유롭게 미끄러짐
전 부품 : 강체 → 변형 에너지 없음
────────────────────────────────────
기구 내부에 저항하는 요소가 전혀 없음
→ 준정적 조건에서 구동력이 필요하지 않음
```

마찰(μ = 0.15)이 정의되어 있었지만, **마찰력은 수직항력에 비례**하고
그 **수직항력 자체가 0에 수렴**하므로 마찰 저항도 0이 된다.

### 조치 — 가정을 명시하고 그 의존성을 함께 밝힘
실제 푸시버튼에는 PIECE를 원위치로 되돌리는 **복귀 스프링**이 존재한다.
과제 조건에 강성이 주어지지 않았으므로, Translator 커넥터(CONN-TRANS)에 Elasticity를 부여하고
**k = 1 N/mm 를 가정**했다.

그리고 결과에 다음을 함께 명시했다.

> **반력은 이 가정에 선형 비례한다.**
> k = 10 N/mm였다면 반력은 약 80 N이 되었을 것이다.
> 실제 설계 스프링 강성이 확정되면 비례 스케일로 즉시 환산 가능하다.

### 배운 것
**"8.17 N"이라는 숫자 자체보다, "저항 조건이 결정되면 반력이 그에 비례해 결정된다"는 구조를 이해하는 것이 중요하다.**
이상적 강체와 이상적 커넥터로만 구성된 기구는 준정적 조건에서 구동에 에너지를 요구하지 않는다.
실제 조작력을 예측하려면 **복귀 스프링, 접촉 마찰, 부품의 탄성 변형** 같은 저항 조건을 반드시 부여해야 한다.

## 4. 강체 참조점에 질량이 없다는 경고

### 증상
커넥터 노드에 질량이 없다는 경고 → **zero pivot** 위험.

### 원인
강체(Rigid body) 참조점에 질량·관성이 정의되지 않았다.
강체 기구는 **접촉이 순간적으로 떨어지면 질량 없는 자유도가 남아** 수치 특이점을 유발한다.

### 조치
`Special > Inertia` 로 각 참조점에 미소 점질량 부여.

| 대상 | 점질량 |
|---|---|
| 부품 참조점 | 1×10⁻⁴ tonne |
| 지면 참조점 | 1×10⁻⁶ tonne |

### 검증
결과 오염 여부를 에너지로 확인했다.

```
ALLKE / ALLWK ≈ 5×10⁻⁶  (0.0005 %)
```

**결과에는 거의 영향을 주지 않으면서 수치 안정성 확보에는 결정적**이었다.
미소 관성으로 자유도를 정규화하는 것은 강체 기구 해석의 표준적인 처방이다.

### 함께 적용한 것 — Static이 아니라 Dynamic, Implicit
4개 부품이 모두 강체이고 저항 요소가 없으면 정적 해석은 특이(singular)해지기 쉽다.
접촉이 순간적으로 분리되면 부품이 자유 부유하기 때문이다.

→ `Static, General` 대신 **`Dynamic, Implicit` + Application: Quasi-static** 사용.
관성으로 정규화하되, 관성이 결과를 지배하지 않는지는 위 에너지 비로 검증했다.

## 6. 커넥터 로컬 축 방향 — 가장 주의를 요한 단계

### 문제
Abaqus에서
- **Hinge** = 로컬 1축 중심의 **회전만** 허용
- **Translator** = 로컬 1축 방향의 **병진만** 허용

**로컬 1축 방향을 잘못 지정하면 기구가 전혀 다른 방식으로 움직인다.**

### 조치
Translator의 로컬 1축을 전역 Z에 맞추기 위해 **Datum CSYS(CSYS-TRANS)** 를 3 Points 방식으로 생성:

| 지정 | 좌표 |
|---|---|
| 원점 | (0, 0, 0) |
| X축상의 점 | (0, 0, 10) |
| XY평면상의 점 | (10, 0, 0) |

이를 Section Assignment의 **Orientation**에 지정했다.

### 부수 문제 — 지면(ground) 참조점 배치
커넥터는 **두 점 사이**에 정의되는 요소다.
"고정된 지면 기준으로 특정 자유도만 허용"을 구현하려면 짝이 되는 지면 참조점이 필요하다.

→ 부품 참조점마다 지면 참조점을 추가 생성 → Wire로 연결 → **Encastre로 완전 구속**

지면 참조점은 부품 참조점과 좌표가 겹쳐 **화면에서 선택이 어려우므로 X방향으로 충분히 이격** 배치했다.

### 검증 — 눈으로 보지 않고 숫자로 확인
"부품이 흩어지지 않고 잘 움직인다"는 육안 확인으로 끝내지 않고,
**참조점의 회전 성분을 History Output으로 판독**했다.

| 참조점 / 변수 | 최종값 | 판정 |
|---|---|---|
| RP-JIG · U3 | −5.0 mm | 강제변위 정상 적용 |
| RP-BUTTON · UR1 | −0.28 rad (≈ −16°) | X축 중심 회전 발생 → **Hinge 정상 작동** |
| RP-BUTTON · UR3 | ≈ 4×10⁻²¹ rad | 허용축 외 회전 없음 → **Hinge 구속 정상** |
| RP-PIECE1 · UR3 | ≈ 10⁻²⁷ rad | 회전 완전 구속 → **Translator 정상** |
| RP-PIECE2 · UR3 | ≈ 10⁻²⁷ rad | 회전 완전 구속 → **Translator 정상** |

## 7. 응력 피크의 신뢰성 — 메시 독립성

### 문제 (2주차)
최대 Von Mises 응력 **393.5 MPa**가 좁은 neck부와 곡률 전환부에 집중되어 나왔다.
그런데 이것이 **실제 응력집중인지, 요소가 성글어 생긴 수치적 피크인지** 구분되지 않았다.

### 조치
개선안 우선순위에 **"고응력부 mesh 세분화 후 재해석 → 메시 독립성 검토 후 최종값 채택"** 을 포함시켰다.

응력집중부는 요소를 줄이면 값이 계속 올라가는 성질이 있어,
**수렴하는지 확인하기 전에는 그 값을 설계 판정에 쓸 수 없다.**

---

## 전체를 통해 정리된 원칙

1. **이상한 값을 만나면 먼저 "물리적으로 가능한가"를 따진다.** 반력 0은 오류가 아니라 답이었다.
2. **주어지지 않은 값은 가정으로 명시하고, 결과가 그 가정에 어떻게 의존하는지 함께 쓴다.**
3. **결과는 독립적인 방법으로 교차검증한다.** 반력은 에너지 수지로, 커넥터 구속은 회전 성분 판독으로.
4. **수렴 실패와 솔버 종료는 다른 문제다.** 전자는 모델, 후자는 옵션 조합을 본다.
5. **경고 메시지를 끝까지 남겨두고 그 영향 범위를 적는다.** `curved/warped` 경고는 해소하지 못했고, 그것이 하중 곡선에 미치는 영향을 명시했다.
